# Ya-Ali 1.0.3 — Data Provenance Plan

## اصل

«زیاد» نباید به معنی رکوردهای ساختگی یا بدون منبع باشد. بانک داخلی باید بین داده آموزشی اصیلِ تولیدشده برای محصول و داده واردشده از corpus عمومی تفاوت بگذارد.

## منابع بررسی‌شده

### Tatoeba

متن‌های Tatoeba برای استفاده مجدد تحت Creative Commons Attribution 2.0 France منتشر می‌شوند و attribution لازم است. مجوز فایل‌های صوتی یکسان نیست و باید برای هر فایل بررسی شود. بنابراین در این نسخه هیچ فایل صوتی Tatoeba داخل APK بسته‌بندی نمی‌شود؛ واردسازی متن باید با ثبت منبع و مجوز انجام شود.

### OPUS

OPUS مجموعه بزرگی از corpusهای چندزبانه است، اما مجوز هر corpus یکسان نیست و برخی منابع محدودیت یا شرایط جداگانه دارند. بنابراین Ya-Ali نباید کل OPUS یا OpenSubtitles را کورکورانه داخل بانک برنامه کپی کند. importer آینده باید corpus، نسخه، URL، license و تاریخ واردسازی را در metadata ثبت کند.

### Mozilla Common Voice

Common Voice داده‌های گفتاری را از طریق Mozilla Data Collective ارائه می‌کند و داده‌های منتشرشده آن، در حالت عمومی اعلام‌شده، CC0 هستند؛ با این حال شرایط استفاده و روش دسترسی فعلی باید هنگام بسته‌بندی بررسی شود. برای STT/voice-pack بهتر است داده‌ها خارج از APK و با manifest نسخه‌دار مدیریت شوند.

## سیاست محصول

- رکورد داخلی آموزشی: `source=yaali-authored`.
- رکورد corpus خارجی: `source=<corpus>` همراه با license/provenance.
- صوت خارجی: فقط با مجوز روشن و ثبت attribution/license.
- هیچ داده‌ای به‌عنوان «واقعی» معرفی نمی‌شود اگر منشأ آن روشن نباشد.
