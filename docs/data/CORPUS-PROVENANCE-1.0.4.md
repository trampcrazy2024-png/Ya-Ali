# Corpus provenance policy

Every imported corpus record must retain source, dataset, dataset version, license and provenance. License strings are copied from the dataset release metadata; they are never inferred from the fact that a website is public.

Common Voice is treated as CC0 only for releases that explicitly state CC0 in Mozilla's current dataset metadata. Other corpora require their own verified license and attribution.

The app stores corpus item type separately (`word`, `phrase`, `sentence`, `dialogue`, `audio`) and keeps audio/speaker metadata separate from text.
