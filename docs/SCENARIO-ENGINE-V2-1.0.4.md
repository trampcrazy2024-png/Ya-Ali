# Scenario Engine V2

Scenario definitions contain persona, goal, context, constraints, success criteria, states, transitions, decision signals, skills and tags.

Transitions can combine keyword, intent, semantic similarity, goal achievement, skill thresholds and custom signals. The runtime returns the selected next state plus confidence and reasons.

Scenario completion produces evaluation dimensions and skill events. Those events feed the learner profile and next-session recommendation rather than ending at a UI report.
